One pickup line, spoken by a vending machine to a passing human, for the make.fun contest "One Line, One Minute: The Vending Machine Pickup Line Contest".

The machine has been humming to itself all day — then a human walks by, its coil spins, its lights blink, and its last chocolate bar gets stuck. On purpose. The joke is the machine staging its own malfunction to get noticed: a stuck snack is the one thing every vending machine does, and here it does it deliberately.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`. The program is deterministic: every run writes the exact same bytes.
